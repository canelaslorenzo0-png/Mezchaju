Install in three steps

Download the APK

Grab mezchaju-v1.1.0.apk from Releases.

Allow sideload

Enable “install unknown apps” for your browser or file manager.

First run

The app sets up a full Linux prefix, installs the harnesses and starts the gateway.

⚠️ First boot downloads Node.js, OpenClaw, DeepSeek Harness and Claw Code into the app’s private storage — allow a few minutes on a good connection.
